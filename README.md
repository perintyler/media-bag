# Media (Barry bag)

View and inspect local image, video, and audio files.

## Tools

- `list_media` — list all media files (images, videos, audio) in a directory
- `view_image` — display an image file
- `view_video` — display a video file for playback
- `view_audio` — display an audio file for playback
- `get_media_info` — get detailed metadata about any media file
